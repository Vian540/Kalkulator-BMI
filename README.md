# BMI Calculator

Kalkulator BMI(Body Mass Index) sederhana yang dibuat menggunakan Java dan JavaFx

## Features

- Input user name
- Input height and weight
- Calculate Body Mass Index (BMI)
- Display the calculation result

## Technologies Used

- Java
- JavaFX 21
- Maven
- Apache NetBeans

## Requirements

- JDK 26
- Apache Maven
- JavaFX dependencies (managed through Maven)

## Cara menjalankan

1. Clone atau download repository ini.
2. Buka project di Apache NetBeans.
3. Izinkan Maven mendownload dependencies yang diperlukan.
4. Jalankan project menggunakan JavaFX Maven plugin.

Alternativenya, dari terminal directory project, jalankan:

```bash
mvn clean javafx:run
```
